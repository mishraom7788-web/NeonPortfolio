OM MISHRA — CYBERPUNK PORTFOLIO
================================

FILES
-----
index.html       Home page
about.html       About page
skills.html      Skills and learning roadmap
projects.html    Project showcase
contact.html     Contact page with email-form interaction
css/style.css    Shared responsive styling
js/script.js     Shared JavaScript interactions

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the NeonPortfolio folder in VS Code.
3. Open index.html in a browser, or use Live Server if it is installed.
4. Use the navigation links to move between all five pages.

IMPORTANT CUSTOMISATIONS
------------------------
1. Open js/script.js.
2. Find: const contactEmail = "your.email@example.com";
3. Replace it with your real email address.
4. In contact.html, replace the placeholder email shown in the contact details if you want the email displayed in the HTML source to match.
5. Edit the sample projects in projects.html so they accurately reflect your own work.
6. Update the profile information in about.html if any details should be different.

CONTACT FORM NOTE
-----------------
The contact form uses mailto: and opens the visitor's default email application.
It does not send messages to a server or save them in a database. A hosted form service
or a backend would be needed for server-based message delivery.

No external libraries or frameworks are required. The website works as static files.
